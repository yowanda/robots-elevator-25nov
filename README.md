One original line of awkward small talk that one robot says to another while they ride an elevator together: it counts the floors in binary to avoid eye contact, then blames its firmware. The program writes that single line, deterministically, to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
